AVENGERS: DOOMSDAY — Command Terminal
A responsive, single-page committee management website designed for GitHub Pages.
Publish with GitHub Pages
Create a new GitHub repository (for example avengers-doomsday).
Upload index.html to the repository root.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select main and / (root), then save. GitHub will provide your public website URL.
Admin access
The starter passcode is DOOM123. Open EB Command Access to manage scoring, lock attendance, edit settings, publish results and manage records. Change the passcode in Command Settings after signing in.
Important data note
This is a static GitHub Pages site. Data is stored in the browser's local storage, so it does not automatically sync between devices or different visitors. Use Export JSON Backup regularly. The built-in passcode is a convenience gate only; it is not secure server-side authentication. Do not enter sensitive personal information.
Customization
Change the initial website title, tagline and passcode in the initial object near the top of the script.
Change the default grading sections in the same object.
Change colours, fonts and layout in the :root CSS variables and stylesheet.
All core UI and functionality is contained in index.html; no build tools are required.
